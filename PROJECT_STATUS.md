## Workflow Oficial de Engenharia

1. Planejamento da missão
2. Desenvolvimento em branch dedicada
3. Auditoria técnica local
4. Commit + Push
5. Auditoria arquitetural no GitHub
6. PR
7. Aprovação e Merge
