# VERO Design System

## Visão Geral

O VERO Design System (VDS) define os padrões visuais, de experiência e de implementação da plataforma VERO. É a fonte oficial para componentes, layouts, identidade visual e regras de interface.

## Estrutura

- VDS-001 — Princípios
- VDS-002 — Design Tokens
- VDS-003 — Component Library
- VDS-004 — Layout Library
- VDS-005 — Brand Engine
- VDS-006 — Vittorio Experience
- VDS-007 — Adaptive Experience

## Diretrizes

- Fonte única de verdade para a interface.
- Componentes reutilizáveis e acessíveis.
- Compatível com Web, Mobile e White Label.
- Toda alteração deve ser versionada por Pull Request.
