# VERO Manager v2.1

## Objetivo

Transformar a base administrativa do VERO Manager v2 em uma experiência operacional completa para administração do cardápio e das configurações essenciais do estabelecimento.

## Escopo prioritário

1. CRUD visual completo de menus, categorias e itens.
2. Criação e edição com validação administrativa e feedback de erro.
3. Seletor de produtos a partir do catálogo VERO existente.
4. Gestão de nome, descrição, imagem, preço, ordenação e destaque.
5. Ativação, pausa e indisponibilidade operacional sem alterar a definição do produto.
6. Publicação e despublicação segura de menus.
7. Configurações essenciais do estabelecimento para operação do cardápio.
8. Estados de loading, vazio, sucesso e erro adequados ao operador.
9. Testes e endurecimento dos fluxos administrativos.
10. CI e Docker verdes antes de promover o PR para Ready e realizar merge.

## Critério de conclusão

O Manager v2.1 somente será considerado concluído quando os fluxos administrativos prioritários estiverem integrados, versionados, auditados e com os gates obrigatórios verdes.
